# SEO Packages for CG Carbon Website

Run the following command to install all required SEO packages:

```bash
npm install next-seo @types/next-seo schema-dts
```

## Package Details

1. **next-seo**: Advanced SEO made easy for Next.js projects
2. **@types/next-seo**: TypeScript definitions for next-seo
3. **schema-dts**: TypeScript definitions for Schema.org JSON-LD

These packages will help implement:
- Proper meta tags
- Structured data (Schema.org)
- Social media tags (Open Graph and Twitter)
- Canonical URLs
- JSON-LD for better rich snippets in search results
